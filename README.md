# Exercise tracker

iPhone camera and laptop pose estimation with Arduino OLED, touch sensor, buzzer, and LED feedback for squats and curls.

Start with [Exercise setup](EXERCISE_SETUP.md), [iPhone setup](PHONE_SETUP.md), and the [presentation guide](PRESENTATION_GUIDE.md).

The pose model is downloaded on first use. The local certificate private keys, virtual environment, logs, and model weights are excluded from version control. This is a prototype and its thresholds are not clinical standards.
